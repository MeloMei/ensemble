# Ensemble 界面风格

## 颜色和尺寸

[界面变量](../src/renderer/ui-kit/tokens.css)定义亮暗主题、文字层级、圆角、强调色和动效时长。其他 React 项目可以引入这份 CSS，通过 `data-theme="dark"` 切换到深色。产品页面通过变量选择颜色和尺寸，终端主题、窗口布局和 Agent 图标留在各自应用。

日常操作用中性色。陶土色用于选中项和需要注意的动作。错误、等待和完成使用各自的状态色，同时保留能读懂的文字或图标。

## 控件

可复用控件放在 `src/renderer/ui-kit/`。控件接受当前值和回调，调用方决定何时保存、是否允许操作，以及保存失败怎么处理。依赖 Ensemble 会话、翻译或 IPC 的组合留在功能代码里。先在真实界面使用，再把第二个项目确实需要的接口提取成包。

## 动效

- 控件的外框、焦点和正在读的内容尽量留在原位。切换选项时更新发生变化的区域。
- 用户拖动时位置跟手。松开后再过渡到合法位置。
- 新事件可以短暂入场。更新同一条记录时保留该行和已展开的详情。重开或浏览历史时直接显示已有内容。
- [RollingText](../src/renderer/ui-kit/RollingText.tsx)保留相同首尾，只滚动变化的部分。调用方在历史加载和页面切换时传入 `animate={false}`。屏幕阅读器读到完整新值，系统开启减少动态效果时直接替换。
- [DetailCard](../src/renderer/ui-kit/DetailCard.tsx)用来预览只读详情。鼠标停留 550 毫秒打开，关闭后 400 毫秒内移到同组控件可直接打开下一张。键盘聚焦时直接显示，按 Escape 可关闭。卡片靠近窗口边缘会换边，原控件保留自己的点击行为。
