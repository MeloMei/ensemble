# Ensemble 标志

[English](README.md)

![Ensemble 标志](ensemble-avatar.png)

这是 Ensemble 的正式 Logo，于 2026 年 10 月 22 日确定。五个独立声部组成一场合奏。

图形由陶土色背景上的五根圆头竖条组成。从左到右依次为深灰、米白、深灰、米白、深灰。不同的高度和上下位置也是定稿的一部分。

## 素材

| 文件 | 尺寸 | 用途 |
| --- | --- | --- |
| [ensemble-logo.png](ensemble-logo.png) | 1254 × 1254 | 定稿原图；用于 README、宣传视频、UI 品牌展示及应用图标导出。 |
| [ensemble-avatar.png](ensemble-avatar.png) | 512 × 512 | README、UI 和 GitHub 头像；由定稿原图等比例缩小。 |

以这两个本地文件为准。缩放或导出时，保留五根竖条、颜色顺序、相对尺寸、间距和陶土色背景。图形本身不含文字。

宣传视频可以让五根竖条运动到定稿位置，最后停留展示完整 Logo。浅色和深色 UI 中，Logo 色块内部都保留定稿配色。
