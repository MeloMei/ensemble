# Ensemble logo

[简体中文](README.zh-CN.md)

![Ensemble logo](ensemble-avatar.png)

This is the official Ensemble logo, adopted on October 22, 2026. Five individual voices form one ensemble.

The mark uses five rounded vertical bars on a terracotta background. From left to right, the bars are graphite, ivory, graphite, ivory, and graphite. Their different heights and vertical positions are part of the approved design.
